🔒 Certificate Vault Tool

Encrypts your certificate files inside this browser — nothing is uploaded anywhere. Open this file by double-clicking it (Chrome / Edge / Firefox).

Use the same password every time (for the verifier and every file). Save it in a password manager. If you forget it, just create a new one and re-encrypt.
